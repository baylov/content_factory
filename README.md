# 🤖 Upbit Notice Telegram Bot

Python бот для мониторинга новых уведомлений на [Upbit](https://upbit.com/service_center/notice) и мгновенной отправки их в Telegram.

## 🎯 Описание проекта

Бот автоматически проверяет страницу уведомлений Upbit каждые 1-2 секунды, обнаруживает новые записи и отправляет уведомления в указанный Telegram чат. Идеально подходит для трейдеров, которым нужно оперативно узнавать о новых листингах, обновлениях и важных объявлениях биржи.

## ✨ Возможности

- ⚡ Молниеносная доставка уведомлений (1-2 секунды)
- 🔄 Автоматическое восстановление после ошибок
- 📝 Детальное логирование всех событий
- 🛡️ Защита от дубликатов уведомлений
- 🎲 Случайные задержки для предотвращения блокировок
- 🔐 Безопасное хранение токенов через .env

## 📋 Технический стек

- Python 3.10+
- requests - HTTP запросы
- beautifulsoup4 - парсинг HTML
- python-dotenv - управление конфигурацией

## 🚀 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository_url>
cd upbit_notice_bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

Или с использованием виртуального окружения (рекомендуется):

```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настройка Telegram бота

#### Создание бота через BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Upbit Notice Monitor")
   - Введите username бота (должен заканчиваться на `bot`, например: "upbit_notice_bot")
4. BotFather отправит вам токен бота в формате: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
5. **Сохраните этот токен** - он понадобится для конфигурации

#### Получение Chat ID

**Метод 1: Через бота** (рекомендуется)
1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте ему любое сообщение
3. Бот ответит с вашим Chat ID

**Метод 2: Через API**
1. Отправьте любое сообщение вашему новому боту
2. Откройте в браузере: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
3. Найдите значение `"chat":{"id":123456789}` - это ваш Chat ID

**Для групповых чатов:**
1. Добавьте бота в группу
2. Отправьте сообщение в группу
3. Используйте метод 2 выше - Chat ID для групп начинается с `-`

### 4. Конфигурация переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и вставьте ваши данные:

```
TELEGRAM_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=123456789
```

⚠️ **Важно:** Никогда не коммитьте файл `.env` в репозиторий!

### Основные функции

#### `fetch_latest_notice()`
- Отправляет HTTP запрос на https://upbit.com/service_center/notice
- Использует User-Agent для имитации браузера
- Парсит HTML с помощью BeautifulSoup
- Ищет первую новость через несколько селекторов (fallback)
- Извлекает заголовок и ссылку
- Возвращает `{"title": "...", "link": "..."}` или `None` при ошибке

#### `read_last_notice()`
- Читает последнюю сохраненную ссылку из `last_notice.txt`
- Возвращает `None` если файл пустой или не существует

#### `save_last_notice(link)`
- Сохраняет ссылку в `last_notice.txt` в кодировке UTF-8

#### `is_new_notice(current_link)`
- Сравнивает текущую ссылку с сохраненной
- Возвращает `True` если новость новая, `False` если та же

#### `send_telegram_notification(title, link)`
- Отправляет форматированное сообщение в Telegram через Bot API
- Использует HTML форматирование
- Логирует успех или ошибку отправки

#### `main()`
- Инициализирует логирование
- При первом запуске сохраняет текущую новость БЕЗ отправки уведомления
- Запускает бесконечный цикл мониторинга с обработкой ошибок
- Корректно завершается при Ctrl+C

## 🛡️ Меры против блокировок

Бот реализует несколько стратегий для предотвращения блокировки со стороны Upbit:

1. **User-Agent**: Имитирует реальный браузер Chrome
2. **Случайные задержки**: 1.0-1.5 секунды между запросами
3. **Обработка ошибок**: При сбоях делает паузу 5 секунд
4. **Таймауты**: 10 секунд на каждый запрос
5. **Graceful degradation**: Продолжает работу даже при временных ошибках

## 🔧 Troubleshooting

### Проблема: Бот не находит новости

**Причина:** Изменилась структура HTML на сайте Upbit

**Решение:**
1. Откройте https://upbit.com/service_center/notice в браузере
2. Откройте DevTools (F12) → Elements
3. Найдите элемент первой новости
4. Обновите селектор в функции `fetch_latest_notice()` в файле `main.py`

### Проблема: Ошибка "TELEGRAM_TOKEN не установлен"

**Причина:** Файл `.env` не создан или содержит ошибки

**Решение:**
1. Убедитесь, что файл `.env` существует в корне проекта
2. Проверьте, что нет пробелов вокруг `=`: `TELEGRAM_TOKEN=your_token`
3. Проверьте, что токен скопирован полностью без лишних символов

### Проблема: Бот отправляет дубликаты

**Причина:** Файл `last_notice.txt` поврежден или удален

**Решение:**
1. Остановите бота (Ctrl+C)
2. Удалите `last_notice.txt`
3. Запустите бота снова - он создаст новый файл

### Проблема: Ошибки "Connection timeout"

**Причина:** Проблемы с сетью или блокировка со стороны Upbit

**Решение:**
1. Проверьте подключение к интернету
2. Попробуйте увеличить задержки в `main()`: `time.sleep(random.uniform(2.0, 3.0))`
3. Используйте прокси или VPN если Upbit блокирует ваш регион

### Проблема: Уведомления приходят с задержкой

**Причина:** Слишком большие интервалы между запросами

**Решение:**
1. Уменьшите задержки (но не ниже 1 секунды): `time.sleep(random.uniform(0.8, 1.2))`
2. Оптимизируйте подключение к интернету
3. Убедитесь, что нет других программ, замедляющих систему
