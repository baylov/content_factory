# 🤖 Upbit Notice Bot

Бот для автоматического мониторинга новостей на [Upbit](https://upbit.com/service_center/notice) и отправки уведомлений в Telegram.

## ⚡ Новая версия: Ultra-Fast JS Parser

**Версия с ультра-быстрым парсером и автоматической диагностикой!**

### 🚀 Производительность
- **< 1 секунда** на цикл (в 2-3 раза быстрее!)
- Умное ожидание с polling 50ms
- JavaScript парсинг с 4 fallback стратегиями

### 🔍 Надежность
- 4 fallback стратегии поиска новостей
- Автоматическая диагностика при ошибках
- Сохранение HTML для анализа
- Умная фильтрация закрепленных новостей

### 📊 Мониторинг
- Детальные метрики на каждом этапе
- Оценка производительности в реальном времени
- Логирование метрик в отдельные файлы

## 🚀 Быстрый старт

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repo-url>
cd upbit-notice-bot
```

2. Установите зависимости:
```bash
pip3 install -r requirements.txt
```

3. Настройте `.env` файл:
```bash
cp .env.example .env
nano .env
```

Добавьте:
```
TELEGRAM_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

### Запуск

```bash
python3 main.py
```

### Тестирование

```bash
# Тест основного функционала
python3 test_selenium.py

# Тест производительности
python3 test_performance.py

# Тест нового ультра-быстрого парсера
python3 test_ultra_fast_parser.py
```

## 🔧 Конфигурация

### Переменные окружения

- `TELEGRAM_TOKEN` - токен Telegram бота
- `TELEGRAM_CHAT_ID` - ID чата для уведомлений

### Настройки в коде

- **Интервал проверки:** 1-2 секунды (случайный)
- **Page load strategy:** `eager` (не ждет все ресурсы)
- **Polling интервал:** 50ms (проверка появления новостей)
- **Max wait:** 0.5-1.0 сек (ожидание новостей)

## 🔍 Диагностика

### Автоматическая диагностика

При ошибках парсинга автоматически:
1. Сохраняется HTML в `upbit_debug.html`
2. Тестируются 8 разных селекторов
3. Выводятся результаты и рекомендации

### Ручная диагностика

```python
from main import init_driver, debug_save_html_and_find_selectors

driver = init_driver()
driver.get("https://upbit.com/service_center/notice")
debug_save_html_and_find_selectors(driver)
driver.quit()
```

## 🎯 Fallback стратегии

Парсер использует 4 стратегии по порядку:

1. **exact_id**: `a[href*="/service_center/notice?id="]` - самый точный
2. **notice_links**: `a[href*="/service_center/notice"]` - шире
3. **tr_notice**: `tr a[href*="notice"]` - строки таблицы
4. **any_id**: `a[href*="id="]` - самый широкий

Если ни одна не работает → запускается автодиагностика!
