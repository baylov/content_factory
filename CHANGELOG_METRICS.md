## ✨ Новые возможности

### 1. Класс MetricsLogger

**Файл:** `main.py` (строки 33-114)

- Новый класс для логирования метрик производительности
- Автоматическая ротация логов (10 МБ, 5 резервных копий)
- Миллисекундная точность временных меток
- Отдельный файл: `logs/performance_metrics.log`

### 2. Детальное логирование метрик

Для каждой обработанной новости записываются:
- **Detected at** - момент обнаружения
- **Processing started** - начало получения данных (с расчетом lag)
- **Processing completed** - завершение обработки (с расчетом duration)
- **Sent to Telegram** - момент отправки в Telegram
- **Total Latency** - общая задержка от обнаружения до отправки

### 3. Футер в Telegram уведомлениях

Каждое Telegram уведомление теперь содержит футер:
```
─────────────────
⏱ Обнаружено: 10:23:45
📤 Отправлено: 10:23:47
⚡️ Задержка: 2.44 сек
```

- Количество резервных копий: 5

Для изменения создайте новый экземпляр:
```python

    log_file="logs/performance_metrics.log",
    max_bytes=20*1024*1024,  # 20 МБ
    backup_count=10           # 10 копий
)
```

## 📋 Примеры использования

```bash
  awk '{sum+=$4; count++} END {print sum/count}'
```
