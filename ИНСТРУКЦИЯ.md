## 📋 A. Системные требования

### Минимальные требования

| Параметр | Значение |
|----------|----------|
| **CPU** | 1 vCPU |
| **RAM** | 1 GB |
| **Диск** | 10 GB |
| **ОС** | Ubuntu 20.04+ / Debian 10+ |
| **Python** | 3.9 или выше |
| **Интернет** | Стабильное соединение |

### Рекомендуемые требования

| Параметр | Значение |
|----------|----------|
| **CPU** | 2 vCPU |
| **RAM** | 2 GB |
| **Диск** | 20 GB SSD |
| **ОС** | Ubuntu 22.04 LTS |
| **Python** | 3.11+ |
| **Локация сервера** | Азия (для минимальной задержки до Upbit) |

> **💡 Примечание**: Бот потребляет около 150-200 MB RAM при работе. Сервер в азиатском регионе обеспечит минимальную сетевую задержку до Upbit (Южная Корея).

## 🔧 B. Установка из архива (пошаговая)

### Шаг 1: Загрузка файлов на сервер

Существует несколько способов загрузить архив с ботом на ваш сервер:

#### Способ 1: Через SCP (из терминала)

Если архив у вас на локальном компьютере:

```bash
scp upbit_bot.zip user@your-server-ip:/home/user/
```

Замените:
- `upbit_bot.zip` — имя вашего архива
- `user` — ваше имя пользователя на сервере
- `your-server-ip` — IP-адрес вашего сервера

#### Способ 2: Через SFTP (FileZilla/WinSCP)

1. Установите **FileZilla** (Linux/Mac/Windows) или **WinSCP** (Windows)
2. Подключитесь к серверу:
   - Хост: IP-адрес вашего сервера
   - Протокол: SFTP
   - Порт: 22
   - Логин и пароль от сервера
3. Перетащите файл архива в домашнюю директорию `/home/user/`

#### Способ 3: Через wget (если архив доступен по ссылке)

Если архив размещён на веб-сервере или в облаке:

```bash
cd ~
wget https://example.com/upbit_bot.zip
```

#### Способ 4: Через curl

Альтернатива wget:

```bash
cd ~
curl -O https://example.com/upbit_bot.zip
```

> **⚠️ После загрузки**: Убедитесь, что файл архива находится в вашей домашней директории (`/home/user/`).

Проверка:

```bash
ls -lh ~/upbit_bot.zip
```

Вывод должен показать файл:

```
-rw-r--r-- 1 user user 1.2M Nov  2 10:00 upbit_bot.zip
```

### Шаг 2: Распаковка архива

Подключитесь к серверу по SSH:

```bash
ssh user@your-server-ip
```

Распакуйте архив:

```bash
cd ~
unzip upbit_bot.zip
```

Если утилита `unzip` не установлена, установите её:

```bash
sudo apt update
sudo apt install unzip -y
```

Затем снова распакуйте:

```bash
unzip upbit_bot.zip
```

Перейдите в директорию проекта:

```bash
cd upbit_bot
```

> **💡 Примечание**: Имя директории может отличаться в зависимости от архива. Используйте `ls` для просмотра содержимого.

Проверьте структуру:

```bash
ls -la
```

Вы должны увидеть:

```
drwxr-xr-x  3 user user  4096 Nov  2 10:00 .
drwxr-xr-x  5 user user  4096 Nov  2 09:59 ..
-rw-r--r--  1 user user    70 Nov  2 10:00 .env.example
```

### Шаг 4: Создание виртуального окружения

Находясь в директории проекта:

```bash
cd ~/upbit_bot
```

Создайте виртуальное окружение:

```bash
python3 -m venv venv
```


```
(venv) user@server:~/upbit_bot$
```

## ⚙️ C. Настройка (детально)

### Создание Telegram бота через @BotFather

#### Шаг 1: Откройте Telegram

Запустите приложение Telegram на телефоне или компьютере.

#### Шаг 2: Найдите @BotFather

В поиске введите: `@BotFather`

Откройте официального бота (синяя галочка подтверждения).

#### Шаг 3: Создайте нового бота

Отправьте команду:

```
/newbot
```

BotFather ответит:

```
Alright, a new bot. How are we going to call it? Please choose a name for your bot.
```

#### Шаг 4: Введите имя бота

Введите отображаемое имя (можно на русском):

```
Upbit Notice Bot
```

BotFather ответит:

```
Good. Now let's choose a username for your bot. It must end in `bot`. Like this, for example: TetrisBot or tetris_bot.
```

#### Шаг 5: Введите username бота

Username должен быть уникальным и заканчиваться на `bot`:

```
upbit_notice_alerts_bot
```

Если имя занято, попробуйте другое:

```
upbit_news_monitor_bot
```

#### Шаг 6: Получите токен

BotFather отправит сообщение:

```
Done! Congratulations on your new bot. You will find it at t.me/upbit_notice_alerts_bot. 
You can now add a description, about section and profile picture for your bot, see /help for a list of commands.

Use this token to access the HTTP API:
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

Keep your token secure and store it safely, it can be used by anyone to control your bot.
```

**✅ Скопируйте токен** — это ваш `TELEGRAM_TOKEN`

### Получение Chat ID

У вас есть несколько способов узнать свой Chat ID:

#### Способ 1: Через @userinfobot

1. Найдите в Telegram бота: `@userinfobot`
2. Нажмите **Start** или отправьте `/start`
3. Бот ответит:

```
Id: 123456789
First Name: Ваше Имя
Username: @your_username
Language: ru
```

**✅ Скопируйте значение `Id`** — это ваш `TELEGRAM_CHAT_ID`

#### Способ 2: Через @getmyid_bot

1. Найдите бота: `@getmyid_bot`
2. Нажмите **Start**
3. Бот отправит ваш ID:

```
Your user ID: 123456789
```

#### Способ 3: Для группового чата

Если вы хотите отправлять уведомления в групповой чат:

1. Создайте группу в Telegram
2. Добавьте вашего бота в группу (найдите по username)
3. Отправьте любое сообщение в группу
4. Откройте в браузере URL (замените `<YOUR_TOKEN>` на ваш токен):

```
https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
```

Пример:

```
https://api.telegram.org/bot1234567890:ABCdefGHIjklMNOpqrsTUVwxyz/getUpdates
```

5. В JSON-ответе найдите:

```json
"chat": {
  "id": -100123456789,
  "title": "Upbit Alerts",
  "type": "supergroup"
}
```

**✅ Значение `id` (с минусом!)** — это ваш `TELEGRAM_CHAT_ID` для группы

#### Способ 4: Через Telegram API (универсальный)

1. Запустите вашего бота и отправьте ему любое сообщение
2. Откройте в браузере:

```
https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
```

3. Найдите в ответе:

```json
"from": {
  "id": 123456789,
  "first_name": "Ваше Имя"
}
```

**✅ Значение `id`** — это ваш `TELEGRAM_CHAT_ID`

### Пример заполненного .env файла

Для группового чата:

## 🔧 E. Запуск в продакшене (фоновый режим)

Есть три основных способа запуска бота в фоновом режиме:

### Вариант 1: через nohup (простой)

**Преимущества:**
- Самый простой способ
- Не требует дополнительных инструментов

**Недостатки:**
- Нет удобного интерфейса для управления
- Нужно искать PID процесса для остановки

**Запуск:**

```bash
cd ~/upbit_bot
source venv/bin/activate
nohup python main.py > bot.log 2>&1 &
```

**Проверка запуска:**

```bash
ps aux | grep main.py
```

Вывод:

```
user  12345  0.5  2.1 234567 123456 ?  S  10:00  0:05 python main.py
```

Запомните **PID** (в примере это `12345`).

**Просмотр логов:**

```bash
tail -f ~/upbit_bot/bot.log
```

---

### Вариант 2: через screen (удобный для отладки)

**Преимущества:**
- Легко подключиться обратно к сессии
- Удобно для отладки
- Можно видеть вывод в реальном времени

**Недостатки:**
- Требует установки screen
- Нет автоматического перезапуска при сбое

**Установка screen:**

```bash
sudo apt install screen -y
```

**Запуск в screen:**

```bash
cd ~/upbit_bot
screen -S upbit_bot
source venv/bin/activate
python main.py
```

Бот запустится в screen-сессии. Вы увидите логи в реальном времени.

**Отключиться от screen (бот продолжит работать):**

Нажмите:
1. `Ctrl + A`
2. Затем `D`

Вы вернётесь в обычный терминал. Бот продолжает работать в фоне.

**Вернуться к сессии:**

```bash
screen -r upbit_bot
```

**Список активных screen-сессий:**

```bash
screen -ls
```

**Остановить бота в screen:**

```bash
screen -r upbit_bot
# Теперь вы внутри сессии
# Нажмите Ctrl + C для остановки бота
```

---

### Вариант 3: через systemd (профессиональный, рекомендуется)

**Преимущества:**
- Автоматический запуск при загрузке сервера
- Автоматический перезапуск при сбоях
- Удобное управление (start/stop/restart/status)
- Интеграция с системными логами

**Недостатки:**
- Чуть сложнее в настройке

#### Шаг 1: Создание service файла

Создайте файл сервиса:

```bash
sudo nano /etc/systemd/system/upbit-bot.service
```

#### Шаг 2: Вставьте конфигурацию

**⚠️ ВАЖНО**: Замените `user` на ваше реальное имя пользователя!

```ini
[Unit]
Description=Upbit Notice Bot
After=network.target

[Service]
Type=simple
User=user
WorkingDirectory=/home/user/upbit_bot
ExecStart=/home/user/upbit_bot/venv/bin/python /home/user/upbit_bot/main.py
Restart=always
RestartSec=10
StandardOutput=append:/home/user/upbit_bot/logs/bot.log
StandardError=append:/home/user/upbit_bot/logs/bot.log

[Install]
WantedBy=multi-user.target
```

**Объяснение параметров:**

- `User=user` — пользователь, от имени которого запускается бот
- `WorkingDirectory=...` — рабочая директория бота
- `ExecStart=...` — команда запуска (полный путь к Python и main.py)
- `Restart=always` — автоматически перезапускать при сбоях
- `RestartSec=10` — ждать 10 секунд перед перезапуском
- `StandardOutput` и `StandardError` — перенаправление логов в файл

**Сохраните файл:**
- `Ctrl + O` → `Enter` → `Ctrl + X`

#### Шаг 3: Перезагрузите systemd

```bash
sudo systemctl daemon-reload
```

#### Шаг 4: Запустите сервис

```bash
sudo systemctl start upbit-bot
```

#### Шаг 5: Проверьте статус

```bash
sudo systemctl status upbit-bot
```

Ожидаемый вывод:

```
● upbit-bot.service - Upbit Notice Bot
     Loaded: loaded (/etc/systemd/system/upbit-bot.service; disabled; vendor preset: enabled)
     Active: active (running) since Sat 2024-11-02 10:15:23 UTC; 5s ago
   Main PID: 12345 (python)
      Tasks: 3 (limit: 4915)
     Memory: 123.4M
        CPU: 2.345s
     CGroup: /system.slice/upbit-bot.service
             └─12345 /home/user/upbit_bot/venv/bin/python /home/user/upbit_bot/main.py
```

Статус должен быть **`active (running)`** — это значит, что бот работает.

#### Шаг 6: Включите автозапуск при загрузке

```bash
sudo systemctl enable upbit-bot
```

```
Detected at: 2024-11-02 14:23:45.234
Processing started: 2024-11-02 14:23:45.240 (lag: 0.006s)
Processing completed: 2024-11-02 14:23:45.512 (duration: 0.272s)
Sent to Telegram: 2024-11-02 14:23:45.578
⚡️ TOTAL LATENCY: 0.344s

```

#### Чтение метрик

**Основные поля:**

- **Detected at** — момент, когда MutationObserver обнаружил изменение в DOM
- **Processing started** — начало извлечения данных новости
  - `lag` — задержка между обнаружением и началом обработки (в идеале < 0.01s)
- **Processing completed** — завершение извлечения данных
  - `duration` — время обработки (обычно 0.1-0.3s)
- **Sent to Telegram** — момент успешной отправки уведомления в Telegram
- **TOTAL LATENCY** — общее время от обнаружения до отправки ⚡

**Оценка производительности:**

- **< 0.5 сек** — ✅ ОТЛИЧНО
- **< 1 сек** — ✅ ХОРОШО
- **1-2 сек** — ⚠️ ПРИЕМЛЕМО
- **> 2 сек** — ❌ МЕДЛЕННО (требует анализа)

## ❓ I. Частые проблемы и решения

### 1. Бот не запускается

#### Проблема: `ModuleNotFoundError: No module named 'selenium'`

**Причина:** Зависимости не установлены или виртуальное окружение не активировано.

**Решение:**

```bash
cd ~/upbit_bot
source venv/bin/activate
pip install -r requirements.txt
```

---

#### Проблема: `python: command not found`

**Причина:** Python не установлен.

**Решение:**

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv -y
```

---

#### Проблема: `Permission denied` при запуске

**Причина:** Нет прав на выполнение файла.

**Решение:**

```bash
chmod +x ~/upbit_bot/main.py
```

Или просто запускайте через `python main.py` вместо `./main.py`.

---

### 2. Нет уведомлений в Telegram

#### Проблема: Бот запускается, но уведомления не приходят

**Причина 1:** Неверный токен бота.

**Решение:**

```bash
cat ~/upbit_bot/.env
```

Убедитесь, что `TELEGRAM_TOKEN` правильный. Проверьте в @BotFather.

---

**Причина 2:** Неверный Chat ID.

**Решение:**

```bash
cat ~/upbit_bot/.env
```

Убедитесь, что `TELEGRAM_CHAT_ID` правильный. Получите через @userinfobot.

---

**Причина 3:** Бот не запущен в Telegram.

**Решение:**

Откройте бота в Telegram и нажмите **Start** или отправьте `/start`.

---

**Причина 4:** Нет соединения с Telegram API.

**Решение:**

Проверьте доступ к интернету:

```bash
ping -c 4 api.telegram.org
```

Если пинг не проходит, проверьте:
- Firewall сервера
- Сетевые настройки
- Блокировки провайдера (в некоторых странах Telegram может быть заблокирован)

---

#### Проблема: Ошибка `Unauthorized` в логах

**Причина:** Неверный токен.

**Решение:**

Создайте нового бота через @BotFather или проверьте токен текущего.

---

### 3. Ошибка ChromeDriver

#### Проблема: `WebDriverException: Message: 'chromedriver' executable needs to be in PATH`

**Причина:** ChromeDriver не установлен или не найден.

**Решение:**

Библиотека `webdriver-manager` должна автоматически загрузить ChromeDriver. Если этого не произошло:

```bash
sudo apt install chromium-chromedriver -y
```

Или установите вручную:

```bash
wget https://chromedriver.storage.googleapis.com/114.0.5735.90/chromedriver_linux64.zip
unzip chromedriver_linux64.zip
sudo mv chromedriver /usr/local/bin/
sudo chmod +x /usr/local/bin/chromedriver
```

---

#### Проблема: `SessionNotCreatedException: Message: session not created: This version of ChromeDriver only supports Chrome version XX`

**Причина:** Несовместимость версий Chrome и ChromeDriver.

**Решение:**

Обновите Chrome:

```bash
sudo apt update
sudo apt upgrade google-chrome-stable -y
```

Или Chromium:

```bash
sudo apt update
sudo apt upgrade chromium-browser -y
```

Библиотека `webdriver-manager` автоматически подберёт совместимую версию ChromeDriver при следующем запуске.

---

### 4. Высокая задержка (> 1 секунды)

#### Проблема: Задержка бота более 1 секунды

**Причина 1:** Медленное сетевое соединение.

**Решение:**

Проверьте пинг до Upbit:

```bash
ping -c 10 upbit.com
```

Если задержка > 100ms, рассмотрите перенос сервера ближе к Южной Корее (AWS Seoul, DigitalOcean Singapore, и т.д.).

---

**Причина 2:** Высокая нагрузка на сервер.

**Решение:**

Проверьте нагрузку:

```bash
top
```

Если CPU > 80% или RAM > 90%, обновите сервер или остановите другие процессы.

---

**Причина 3:** Блокировка или throttling со стороны Upbit.

**Решение:**

Проверьте логи на наличие ошибок `403 Forbidden` или `429 Too Many Requests`.

Если есть, возможно, IP-адрес заблокирован. Попробуйте:
- Использовать другой сервер
- Добавить прокси
- Увеличить интервал проверки (не рекомендуется)

---

### 5. Бот перестал работать

#### Проблема: Бот внезапно остановился

**Причина:** Ошибка в коде или потеря соединения.

**Решение:**

Проверьте логи:

```bash
tail -n 100 ~/upbit_bot/logs/bot.log
```

Ищите строки с `ERROR` или `CRITICAL`.

Если используете systemd с `Restart=always`, бот должен автоматически перезапуститься.

Если используете nohup или screen, перезапустите вручную.

---

#### Проблема: Процесс работает, но ничего не происходит

**Причина:** Страница Upbit не загрузилась или MutationObserver не работает.

**Решение:**

Перезапустите бота:

```bash
# Если через systemd
sudo systemctl restart upbit-bot

# Если через nohup
pkill -f main.py
cd ~/upbit_bot && source venv/bin/activate && nohup python main.py > bot.log 2>&1 &
```
