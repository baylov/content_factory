# 🚀 Инструкция по установке и запуску Upbit Notice Bot

Пошаговое руководство по развёртыванию бота на сервере.

---

## 📋 A. Системные требования

### Минимальные требования
- **CPU**: 1 vCPU
- **RAM**: 1 GB
- **Диск**: 10 GB
- **ОС**: Ubuntu 20.04+ / Debian 10+ / любой Linux с поддержкой Chrome
- **Python**: 3.9 или выше
- **Интернет**: Стабильное соединение

### Рекомендуемые требования
- **CPU**: 2 vCPU
- **RAM**: 2 GB
- **Диск**: 20 GB SSD
- **ОС**: Ubuntu 22.04 LTS
- **Python**: 3.11+

> **💡 Примечание**: Бот потребляет около 150-200 MB RAM при работе.

---

## 🔧 B. Установка (пошаговая)

### Шаг 1: Обновление системы

Подключитесь к серверу по SSH и обновите систему:

```bash
sudo apt update && sudo apt upgrade -y
```

### Шаг 2: Установка Python и pip

Проверьте версию Python:

```bash
python3 --version
```

Если Python не установлен или версия ниже 3.9, установите:

```bash
sudo apt install python3 python3-pip python3-venv -y
```

Проверьте версию pip:

```bash
pip3 --version
```

### Шаг 3: Установка Git

```bash
sudo apt install git -y
```

Проверьте установку:

```bash
git --version
```

### Шаг 4: Клонирование репозитория

Перейдите в домашнюю директорию и клонируйте проект:

```bash
cd ~
git clone https://github.com/ваш-репозиторий/upbit-notice-bot.git
cd upbit-notice-bot
```

> **⚠️ Замените** `https://github.com/ваш-репозиторий/upbit-notice-bot.git` на ваш реальный URL репозитория.

### Шаг 5: Создание виртуального окружения

Создайте виртуальное окружение Python:

```bash
python3 -m venv venv
```

Активируйте виртуальное окружение:

```bash
source venv/bin/activate
```

После активации в начале строки появится `(venv)`:

```
(venv) user@server:~/upbit-notice-bot$
```

### Шаг 6: Установка зависимостей Python

Установите все необходимые библиотеки:

```bash
pip install -r requirements.txt
```

Дождитесь завершения установки. Вы увидите сообщение:

```
Successfully installed selenium-... requests-... beautifulsoup4-...
```

### Шаг 7: Установка Chrome/Chromium и ChromeDriver

#### Для Ubuntu/Debian:

Установите Chromium:

```bash
sudo apt install chromium-browser chromium-chromedriver -y
```

Проверьте установку:

```bash
chromium-browser --version
chromedriver --version
```

#### Альтернатива — Google Chrome:

Если Chromium не работает, установите Google Chrome:

```bash
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo dpkg -i google-chrome-stable_current_amd64.deb
sudo apt --fix-broken install -y
```

Проверьте:

```bash
google-chrome --version
```

> **💡 Примечание**: Библиотека `webdriver-manager` автоматически загрузит и установит ChromeDriver при первом запуске бота.

## ⚙️ C. Настройка

### Шаг 1: Создание Telegram бота

#### 1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)

#### 2. Отправьте команду `/newbot`

#### 3. Введите имя бота (отображаемое имя):
```
Upbit Notice Bot
```

#### 4. Введите username бота (должен заканчиваться на `bot`):
```
upbit_notice_alerts_bot
```

#### 5. Скопируйте токен

BotFather отправит вам токен в формате:
```
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

**⚠️ Сохраните этот токен** — он понадобится для настройки.

### Шаг 2: Получение Chat ID

#### Способ 1 — через @userinfobot

1. Откройте бота [@userinfobot](https://t.me/userinfobot) в Telegram
2. Нажмите **Start**
3. Бот отправит вам ваш ID:
```
Your user ID: 123456789
```

#### Способ 2 — через @getmyid_bot

1. Откройте бота [@getmyid_bot](https://t.me/getmyid_bot)
2. Нажмите **Start**
3. Бот отправит:
```
Your user ID: 123456789
```

#### Для группового чата:

1. Добавьте бота в группу
2. Отправьте любое сообщение в группу
3. Откройте в браузере:
```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
```
4. Найдите в JSON `"chat":{"id":-100123456789}`

**⚠️ Сохраните Chat ID** — он понадобится для настройки.

### Шаг 3: Настройка переменных окружения

Находясь в директории проекта:

```bash
cd ~/upbit-notice-bot
```

Скопируйте пример файла `.env`:

```bash
cp .env.example .env
```

Откройте файл `.env` в текстовом редакторе:

```bash
nano .env
```

Замените значения на ваши реальные:

```env
TELEGRAM_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=123456789
```

**Нажмите**:
- `Ctrl + O` (сохранить)
- `Enter` (подтвердить)
- `Ctrl + X` (выйти)

### Шаг 4: Проверка настроек

Убедитесь, что файл `.env` создан и содержит правильные данные:

```bash
cat .env
```

Вывод должен быть:

```
TELEGRAM_TOKEN=ваш_реальный_токен
TELEGRAM_CHAT_ID=ваш_реальный_chat_id
```

> **⚠️ ВАЖНО**: Никогда не делитесь содержимым `.env` файла и не добавляйте его в Git!

## 🚀 D. Запуск

### Вариант 1: Запуск вручную (для тестирования)

Активируйте виртуальное окружение:

```bash
cd ~/upbit-notice-bot
source venv/bin/activate
```

Запустите бота:

```bash
python3 main.py
```

Вы должны увидеть:

```
🚀 Upbit Notice Bot запущен
📡 Режим: MutationObserver (мгновенное обнаружение)
✅ Браузер Chrome запущен в оптимизированном режиме
📡 Подключаемся к Upbit...
✅ MutationObserver установлен
👀 Мониторинг активен
```

Для остановки нажмите `Ctrl + C`.

### Вариант 2: Запуск в фоновом режиме (nohup)

Для запуска бота, который продолжит работать после закрытия SSH:

```bash
cd ~/upbit-notice-bot
source venv/bin/activate
nohup python3 main.py > output.log 2>&1 &
```

Проверьте, что процесс запущен:

```bash
ps aux | grep main.py
```

Вывод:

```
user  12345  0.5  2.1  ... python3 main.py
```

### Вариант 3: Запуск через screen

Screen позволяет легко вернуться к сессии:

#### Установка screen (если не установлен):

```bash
sudo apt install screen -y
```

#### Запуск в screen:

```bash
cd ~/upbit-notice-bot
screen -S upbit_bot
source venv/bin/activate
python3 main.py
```

**Отключиться** от screen (бот продолжит работать):
- Нажмите `Ctrl + A`, затем `D`

**Вернуться** к сессии:

```bash
screen -r upbit_bot
```

**Список активных screen-сессий**:

```bash
screen -ls
```

### Вариант 4: Запуск через tmux

Альтернатива screen:

#### Установка tmux:

```bash
sudo apt install tmux -y
```

#### Запуск в tmux:

```bash
cd ~/upbit-notice-bot
tmux new -s upbit_bot
source venv/bin/activate
python3 main.py
```

**Отключиться** от tmux:
- Нажмите `Ctrl + B`, затем `D`

**Вернуться**:

```bash
tmux attach -t upbit_bot
```

**Список сессий**:

```bash
tmux ls
```

### Вариант 5: Создание systemd сервиса (рекомендуется для продакшена)

Создайте файл сервиса:

```bash
sudo nano /etc/systemd/system/upbit-bot.service
```

Вставьте следующее содержимое (замените `user` на ваше имя пользователя):

```ini
[Unit]
Description=Upbit Notice Bot
After=network.target

[Service]
Type=simple
User=user
WorkingDirectory=/home/user/upbit-notice-bot
ExecStart=/home/user/upbit-notice-bot/venv/bin/python3 /home/user/upbit-notice-bot/main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Сохраните (`Ctrl + O`, `Enter`, `Ctrl + X`).

Перезагрузите systemd:

```bash
sudo systemctl daemon-reload
```

Запустите сервис:

```bash
sudo systemctl start upbit-bot
```

Проверьте статус:

```bash
sudo systemctl status upbit-bot
```

Включите автозапуск при перезагрузке сервера:

```bash
sudo systemctl enable upbit-bot
```

## 🔍 E. Мониторинг

### Проверка работы бота

#### Проверка процесса:

```bash
ps aux | grep main.py
```

Если бот работает, вы увидите:

```
user  12345  0.5  2.1  ... python3 main.py
```

#### Проверка через systemd (если используете сервис):

```bash
sudo systemctl status upbit-bot
```

Статус должен быть `active (running)`.

### Просмотр логов

#### Просмотр последних 50 строк:

```bash
tail -n 50 ~/upbit-notice-bot/logs/bot.log
```

#### Просмотр логов в реальном времени:

```bash
tail -f ~/upbit-notice-bot/logs/bot.log
```

Для остановки нажмите `Ctrl + C`.

#### Просмотр метрик производительности:

```bash
tail -n 100 ~/upbit-notice-bot/logs/performance_metrics.log
```

#### Просмотр метрик в реальном времени:

```bash
tail -f ~/upbit-notice-bot/logs/performance_metrics.log
```

### Понимание метрик

В файле `performance_metrics.log` вы увидите записи вида:

```
[2024-11-02 14:23:45.234] ━━━ NEW ARTICLE ━━━
Source: Upbit Notice
ID: 5710 | Title: "[Upbit] 원화 마켓 AVAX 거래 일시 중단 안내"
Detected at: 2024-11-02 14:23:45.234
Processing started: 2024-11-02 14:23:45.240 (lag: 0.006s)
Processing completed: 2024-11-02 14:23:45.512 (duration: 0.272s)
Sent to Telegram: 2024-11-02 14:23:45.578
⚡️ TOTAL LATENCY: 0.344s
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Расшифровка**:
- **Detected at** — момент обнаружения новости MutationObserver'ом
- **Processing started** — начало извлечения данных
- **lag** — задержка между обнаружением и началом обработки (обычно ~0.006s)
- **Processing completed** — завершение извлечения данных
- **duration** — время обработки (обычно 0.2-0.3s)
- **Sent to Telegram** — момент отправки в Telegram
- **TOTAL LATENCY** — полная задержка от обнаружения до отправки

### Использование logrotate (для автоматической ротации логов)

Создайте конфигурацию logrotate:

```bash
sudo nano /etc/logrotate.d/upbit-bot
```

Вставьте:

```
/home/user/upbit-notice-bot/logs/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 0644 user user
}
```

Замените `user` на ваше имя пользователя.

Сохраните и закройте.

## 🛑 F. Остановка и перезапуск

### Остановка бота

#### Если запущен вручную или через nohup:

Найдите PID процесса:

```bash
ps aux | grep main.py
```

Остановите по PID:

```bash
kill 12345
```

Где `12345` — это PID из вывода `ps aux`.

Или остановите все процессы main.py:

```bash
pkill -f main.py
```

#### Если запущен через screen:

```bash
screen -r upbit_bot
```

Нажмите `Ctrl + C` для остановки, затем `exit` для закрытия сессии.

#### Если запущен через tmux:

```bash
tmux attach -t upbit_bot
```

Нажмите `Ctrl + C`, затем `exit`.

#### Если запущен как systemd сервис:

```bash
sudo systemctl stop upbit-bot
```

### Перезапуск бота

#### Через systemd:

```bash
sudo systemctl restart upbit-bot
```

#### Через screen:

```bash
screen -r upbit_bot
# Нажмите Ctrl + C
python3 main.py
# Нажмите Ctrl + A, затем D
```

#### Через nohup:

```bash
pkill -f main.py
cd ~/upbit-notice-bot
source venv/bin/activate
nohup python3 main.py > output.log 2>&1 &
```

## 🔄 G. Обновление кода

Когда нужно обновить бота до новой версии:

### Шаг 1: Остановите бота

```bash
# Если через systemd:
sudo systemctl stop upbit-bot

# Если через nohup:
pkill -f main.py
```

### Шаг 2: Перейдите в директорию проекта

```bash
cd ~/upbit-notice-bot
```

### Шаг 3: Сохраните файл .env (на всякий случай)

```bash
cp .env .env.backup
```

### Шаг 4: Получите последнюю версию из Git

```bash
git pull origin main
```

> **⚠️ Замените** `main` на название вашей ветки, если она другая.

Если Git сообщает о конфликтах:

```bash
git stash
git pull origin main
git stash pop
```

### Шаг 5: Обновите зависимости (если они изменились)

```bash
source venv/bin/activate
pip install -r requirements.txt --upgrade
```

### Шаг 6: Перезапустите бота

```bash
# Если через systemd:
sudo systemctl start upbit-bot

# Если через nohup:
nohup python3 main.py > output.log 2>&1 &
```

### Шаг 7: Проверьте работу

```bash
tail -f ~/upbit-notice-bot/logs/bot.log
```

## ⚠️ H. Частые проблемы и решения

### Проблема 1: Бот не запускается

#### Симптомы:
```
ModuleNotFoundError: No module named 'selenium'
```

#### Решение:

Убедитесь, что виртуальное окружение активировано:

```bash
cd ~/upbit-notice-bot
source venv/bin/activate
```

Переустановите зависимости:

```bash
pip install -r requirements.txt
```

---

### Проблема 2: Нет уведомлений в Telegram

#### Симптомы:
В логах:
```
❌ Ошибка отправки в Telegram: Unauthorized
```

#### Решение:

Проверьте правильность токена бота:

```bash
cat .env
```

Убедитесь, что `TELEGRAM_TOKEN` правильный.

Проверьте, запустили ли вы бота в Telegram:
1. Найдите вашего бота по username
2. Нажмите **Start** или отправьте `/start`

#### Симптомы:
```
❌ Ошибка отправки в Telegram: Bad Request: chat not found
```

#### Решение:

Неверный `TELEGRAM_CHAT_ID`.

Получите правильный Chat ID через [@userinfobot](https://t.me/userinfobot).

Обновите `.env`:

```bash
nano .env
```

Перезапустите бота.

---

### Проблема 3: Ошибка ChromeDriver

#### Симптомы:
```
❌ Ошибка инициализации браузера: 'chromedriver' executable needs to be in PATH
```

#### Решение:

Установите ChromeDriver:

```bash
sudo apt install chromium-chromedriver -y
```

Или дайте права на автоматическую установку:

```bash
pip install webdriver-manager --upgrade
```

Перезапустите бота.

#### Симптомы:
```
Message: session not created: This version of ChromeDriver only supports Chrome version 118
```

#### Решение:

Обновите Chrome:

```bash
sudo apt update
sudo apt upgrade chromium-browser -y
```

Или установите последний Chrome:

```bash
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo dpkg -i google-chrome-stable_current_amd64.deb
```

---

### Проблема 4: Высокая задержка (latency > 2 сек)

#### Возможные причины:
- Медленное интернет-соединение
- Перегрузка сервера
- Проблемы с API Telegram

#### Решение:

Проверьте скорость интернета:

```bash
wget -O /dev/null http://speedtest.wdc01.softlayer.com/downloads/test10.zip
```

Проверьте загрузку сервера:

```bash
top
```

Если CPU или RAM загружены на > 80%, рассмотрите апгрейд сервера.

Проверьте доступность Telegram API:

```bash
curl https://api.telegram.org
```

Должен вернуться JSON:
```json
{"ok":true,"result":true}
```

---

### Проблема 5: Бот постоянно перезапускается

#### Симптомы:
В логах повторяется:
```
❌ Ошибка (SessionNotCreatedException): session not created
⚠️ Переинициализация...
```

#### Решение:

Переустановите Chrome и ChromeDriver:

```bash
sudo apt remove chromium-browser chromium-chromedriver -y
sudo apt autoremove -y
sudo apt update
sudo apt install chromium-browser chromium-chromedriver -y
```

Перезапустите бота.

---

### Проблема 6: Бот не обнаруживает новые новости

#### Симптомы:
Логи показывают активность, но новости не приходят.

#### Решение:

Проверьте файл `last_notice.txt`:

```bash
cat ~/upbit-notice-bot/last_notice.txt
```

Удалите файл для полного сброса:

```bash
rm ~/upbit-notice-bot/last_notice.txt
```

Перезапустите бота:

```bash
sudo systemctl restart upbit-bot
```

Бот отправит текущую последнюю новость и начнёт мониторинг заново.

---

### Проблема 7: Логи занимают слишком много места

#### Решение:

Очистите старые логи:

```bash
cd ~/upbit-notice-bot/logs
> bot.log
> performance_metrics.log
```

Или настройте logrotate (см. раздел "Мониторинг").
