# 📋 О проекте Upbit Notice Bot

## 🤖 Что это такое

Upbit Notice Bot — это автоматизированный бот для **мгновенного мониторинга новостей** на бирже Upbit с отправкой уведомлений в Telegram.

Бот отслеживает страницу https://upbit.com/service_center/notice в **режиме реального времени** и моментально отправляет уведомление в Telegram при появлении новой публикации.

---

## ⚙️ Как это работает

### 🔍 Технический принцип работы

1. **Загрузка страницы**
   - Бот использует **Selenium WebDriver** с headless Chrome для открытия страницы новостей Upbit
   - Браузер работает в фоновом режиме (без графического интерфейса)
   - Страница загружается один раз и остается открытой на протяжении всей работы бота

2. **Мониторинг изменений в реальном времени**
   - После загрузки страницы бот внедряет на неё **JavaScript MutationObserver**
   - MutationObserver — это встроенная браузерная технология, которая отслеживает любые изменения в HTML-структуре страницы
   - Каждые **0.1 секунды** бот проверяет, произошли ли изменения в таблице новостей
   - Благодаря этому новая новость обнаруживается **мгновенно** — без необходимости постоянно обновлять страницу

3. **Извлечение данных новости**
   - При обнаружении изменений бот через JavaScript получает данные первой незакреплённой новости:
     * **ID** новости (например, `5710`)
     * **Заголовок** новости (текст объявления)
     * **Ссылку** на новость (полный URL)
   
4. **Фильтрация закреплённых новостей**
   - Бот **пропускает закреплённые** (pinned) новости
   - Закреплённые новости определяются по двум маркерам:
     * Текст маркера `"공지"` (означает "объявление" на корейском)
     * Иконка булавки (`pin`) в HTML
   - Это позволяет отслеживать только реальные новые публикации

5. **Отслеживание по ID**
   - Бот запоминает **максимальный ID** новости, которая уже была обработана
   - При появлении новости с **ID больше** сохранённого, бот распознаёт её как новую
   - Это гарантирует, что ни одна новость не будет пропущена или продублирована

6. **Отправка уведомления в Telegram**
   - Бот формирует красивое уведомление с:
     * Заголовком новости
     * Прямой ссылкой на новость
     * Временем обнаружения
     * Временем отправки
     * Задержкой между обнаружением и отправкой
   - Уведомление отправляется через **Telegram Bot API**

7. **Логирование всех этапов**
   - Каждый этап обработки логируется с **миллисекундной точностью**
   - Все метрики сохраняются в отдельный файл `logs/performance_metrics.log`
   - Общие логи работы бота сохраняются в `logs/bot.log`

### 🔄 Периодическое обновление

- Каждые **~5 минут** (3000 проверок по 0.1 сек) бот делает полное обновление страницы
- Это защищает от потери соединения и обеспечивает стабильную работу
- После обновления MutationObserver переустанавливается автоматически

## 🛠 Технологии

### Языки и фреймворки
- **Python 3.11** — основной язык программирования
- **Selenium WebDriver** — для управления браузером и выполнения JavaScript
- **BeautifulSoup4** — для парсинга HTML (резервный метод)
- **python-dotenv** — для управления переменными окружения

### Браузер и автоматизация
- **Chrome/Chromium** в headless режиме — работает без графического интерфейса
- **ChromeDriver** — драйвер для управления браузером
- **webdriver-manager** — автоматическая установка и обновление ChromeDriver

### JavaScript в браузере
- **MutationObserver** — встроенная браузерная технология для отслеживания изменений DOM
- Кастомный JavaScript код для извлечения данных со страницы

### API и уведомления
- **python-telegram-bot** — библиотека для работы с Telegram Bot API
- **requests** — для HTTP-запросов к Telegram API

## ⚡ Производительность

### Скорость работы
- **Задержка от публикации до уведомления**: обычно **0.2–0.5 секунды**
- В идеальных условиях задержка может быть **менее 0.3 секунды**
- Максимальная задержка редко превышает **1 секунду**

### Метрики в реальном времени

Бот логирует детальные метрики для каждой новости:
- ⏱️ **Время обнаружения** — момент, когда MutationObserver зафиксировал изменение
- 🔄 **Время начала обработки** — когда начали извлекать данные новости
- ✅ **Время завершения обработки** — когда все данные получены
- 📤 **Время отправки в Telegram** — когда уведомление отправлено
- ⚡ **Общая задержка (latency)** — от обнаружения до отправки

### Оценка задержки

Бот автоматически оценивает свою производительность:
- ✅ **< 0.5 сек** — ОТЛИЧНО
- ✅ **< 1 сек** — ХОРОШО
- ⚠️ **1–2 сек** — ПРИЕМЛЕМО
- ❌ **> 2 сек** — МЕДЛЕННО (требует внимания)

### Основные файлы

#### `main.py`
Главный файл бота, содержащий весь код:
- Инициализация Selenium WebDriver
- Установка MutationObserver
- Извлечение данных новостей
- Отправка уведомлений в Telegram
- Логирование метрик

#### `requirements.txt`
Список всех Python-зависимостей:
```txt
requests
beautifulsoup4
python-dotenv
selenium
webdriver-manager
```

#### `.env`
Файл с конфиденциальными данными (не включен в Git):
```env
TELEGRAM_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
```

#### `logs/bot.log`
Основной лог работы бота:
- Старт/остановка бота
- Обнаруженные новости
- Отправленные уведомления
- Ошибки и предупреждения

#### `logs/performance_metrics.log`
Детальные метрики производительности:
- Точные временные метки с миллисекундами
- Время обнаружения, обработки, отправки
- Общая задержка (latency) для каждой новости

#### `last_notice.txt`
Хранит ID последней обработанной новости:
```

```

**Расшифровка полей:**
- **Detected at** — момент обнаружения изменений MutationObserver

- **Processing completed** — завершение извлечения данных (duration = время обработки)
- **Sent to Telegram** — момент успешной отправки уведомления
- **TOTAL LATENCY** — общая задержка от обнаружения до отправки

## 🎯 Особенности

### ✅ Преимущества

- **Мгновенное обнаружение** — благодаря MutationObserver, без постоянных обновлений страницы
- **Низкая задержка** — 0.2–0.5 секунды от публикации до уведомления
- **Надёжность** — автоматическое восстановление при сбоях
- **Детальные метрики** — полная прозрачность работы бота
- **Фильтрация** — закреплённые новости пропускаются автоматически
- **Отслеживание по ID** — гарантия отсутствия дубликатов и пропусков

### ⚠️ Ограничения

- Требует стабильного интернет-соединения
- Использует headless браузер (потребляет ~150-200 MB RAM)
- Зависит от стабильности API Telegram
- Требует запущенного Chrome/Chromium
