## 🛠️ Технические детали

### Почему requests не работает?

Upbit использует **Single Page Application (SPA)**:
1. Начальный HTML почти пустой
2. JavaScript загружается и выполняется
3. JavaScript делает API запросы
4. DOM обновляется динамически

**Решение**: Найти тот самый API, который использует JavaScript!

### Как найти API?

1. **Chrome DevTools** → Network → Fetch/XHR
2. Искать запросы с JSON response
3. Искать ключевые слова: notice, announcement, board, list
4. Проверить что возвращается список новостей

### Как найти WebSocket?

1. **Chrome DevTools** → Network → WS
2. Искать `wss://` соединения
3. Проверить Messages tab
4. Искать данные о новостях
