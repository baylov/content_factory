## 🔧 Технические детали

### Почему requests не работает?

Upbit использует **Single Page Application (SPA)** с JavaScript рендерингом:

1. HTTP запрос получает пустой HTML
2. JavaScript загружает данные после загрузки страницы
3. DOM обновляется динамически
4. requests видит только пустой HTML

**Решение**: Нужен метод который:
- Либо перехватывает API запросы (найти API)
- Либо подключается к real-time каналу (WebSocket)
- Либо использует Selenium (текущий метод)
